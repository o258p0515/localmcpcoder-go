# Writing skills
- Create one folder per skill under the configured skills directory and put `SKILL.md` inside it.
- Begin with YAML frontmatter containing a unique lowercase `name` and a trigger-oriented `description`.
- Write concise imperative instructions; explain when the skill applies and what actions to take.
- Keep built-in skills under 120 lines and avoid duplicating generic guidance.
- Use a descriptive name with letters, digits, and hyphens; user skills override built-ins by name.
- Add examples only when they make the procedure materially clearer.
